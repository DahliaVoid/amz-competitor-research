# 产品市场调研与开发决策 Skill

面向产品开发与电商经营的跨类目市场调研。围绕“谁在买、为什么买、愿意为什么多付钱、做出来是否赚钱”进行分析。

## 功能

- 品牌销量/销售额份额与竞争格局
- 类目评分、评价数量与差评痛点
- 头部、新品、直接竞品拆解
- 核心功能 TAG 与细分价格带
- 溢价功能的真实需求与支付意愿
- 成本、利润、盈亏条件与敏感性
- 开发优先级与推进建议

按用户指定阶段执行，不自动扩展为采购、广告投放或发布。

## 使用方法

1. **说明目标**：类目/市场、目标人群、使用场景、要回答的商业问题。
2. **选择数据方式**：用户提供数据、Agent 采集或混合输入。
3. **确认关键参数**：平台、地区、币种、价格口径、样本范围、利润目标等。
4. **执行当前阶段**：品类认知 / 数据整理 / 专项分析 / 完整调研。
5. **交付报告**：先给商业结论，再展开分析；缺数据处标注“待确认”，不编造数据。

## 输出

通常包括：总结与开发建议、市场与品牌格局、评分与用户痛点、竞品拆解、功能与价格带、溢价需求、成本利润测算、产品方案与优先动作。
